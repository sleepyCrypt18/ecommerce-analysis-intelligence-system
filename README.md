# ecommerce-analysis-intelligence-system
E-commerce Data Analysis and Customer Segmentation using Python, Pandas, Plotly and Machine Learning
E-commerce Analysis Intelligence System

An E-commerce Data Analysis and Intelligence System developed using Python to analyse sales transactions, understand customer purchasing behaviour, and identify meaningful customer segments using data analytics and machine learning.

Project Overview

This project analyses an e-commerce transaction dataset containing 10,000 records. It provides insights into revenue, product performance, customer behaviour, and purchasing patterns through interactive visualisations and analytical techniques.

Key Features

- Analysis of 10,000 e-commerce transactions.
- Revenue and sales performance analysis.
- Key Performance Indicators (KPIs).
- Interactive charts and visualisations using Plotly.
- Product and category analysis.
- Country-wise sales analysis.
- RFM (Recency, Frequency, Monetary) customer segmentation.
- Customer clustering using K-Means.
- Data filtering using interactive dropdown widgets.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- StandardScaler
- K-Means Clustering
- Google Colab
- IPyWidgets

Machine Learning

The project uses K-Means clustering with four clusters to group customers based on their purchasing behaviour.

RFM analysis is also performed using:

- Recency
- Frequency
- Monetary Value

Dataset

The project uses a synthetic dataset containing 10,000 e-commerce transactions with information such as:

- Customer ID
- Product
- Category
- Country
- Revenue
- Transaction details

How to Run

1. Download the ".ipynb" notebook.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Run the cells sequentially.

Project Objective

To demonstrate practical applications of data analysis, interactive visualisation, customer segmentation, and machine learning in the e-commerce domain.
